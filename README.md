## Getting Started

To run the portfolio locally, clone the repository and install its dependencies.

```bash
git clone <repository-url>
cd <repository-folder>
npm install
npm run dev
```

Open the local development URL displayed in your terminal.

**Note:** These are standard npm development commands. Verify the actual package manager and scripts in `package.json` before running them.
